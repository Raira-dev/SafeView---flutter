# Checklist final antes do portal FIAP

- [ ] Preencher nomes completos e RMs em README.md e ENTREGA.txt (grupo de até 3 pessoas).
- [ ] Executar `flutter create . --platforms=android,ios,web` se os diretórios nativos ainda não existirem.
- [ ] Executar `flutter pub get`, `flutter analyze`, `flutter test` e `flutter run`.
- [ ] Testar em dois tamanhos de tela e com leitor de tela.
- [ ] Capturar todas as telas reais e salvar em `assets/screenshots/`; atualizar seção de demonstração do README.
- [ ] Gerar APK release e publicar em GitHub Releases, se possível.
- [ ] Gravar vídeo de até 3 minutos seguindo `docs/roteiro-pitch.md`; disponibilizar link público.
- [ ] Criar repositório GitHub público, fazer commits descritivos e não versionar credenciais.
- [ ] Atualizar links do GitHub e vídeo em `ENTREGA.txt`.
- [ ] Compactar a pasta do projeto se o portal FIAP solicitar.
